# הסטודיו של שייה ואלמה — "סטודיו פלא"

אפליקציית אנגלית אישית לשתי אחיות (3 ו־5), בעברית, לטאבלט. Web/PWA ללא תלות בבנייה.

## הפעלה
```bash
npm start            # node server.js → http://localhost:8080
```
- בטאבלט: לפתוח את הכתובת (באותה רשת, `http://<כתובת-המחשב>:8080`) או לארח את התיקייה בכל אחסון סטטי עם HTTPS (Netlify / GitHub Pages / Cloudflare Pages).
- התקנה כאפליקציה: Safari ← שיתוף ← "הוספה למסך הבית"; Chrome ← "התקנת אפליקציה". מצב לא מקוון עובד אחרי טעינה ראשונה (Service Worker; דורש HTTPS או localhost).
- בדיקת מסלול קריטי: `node server.js & npm test` (מריץ "ילדה רובוטית" במגע על כל המסלולים).

## מבנה
| תיקייה | תפקיד |
|---|---|
| `src/content/` | תוכן בלבד: אוצר מילים, תוכנית העונה, תסריט בית הקפה, תגובות, ניסוחים. |
| `src/engine/progress.js` | מנוע ראיות: 5 שלבים לכל מילה/מבנה, מתזמן חזרות, הפחתת עזרה בעברית. |
| `src/engine/store.js` | פרופילים, הגדרות, יצירות – נשמר מקומית במכשיר. |
| `src/engine/voice.js` | הקראה (Web Speech), אפקטים (WebAudio), זיהוי דיבור אופציונלי. |
| `src/engine/stage.js` | במה: שחקנים, אביזרים, בועות, המתנה למגע עם סולם רמזים, גרירה סלחנית. |
| `src/art/` | הדמויות והתפאורות (SVG בסגנון בובות לבד). |
| `src/ui/` | מסך הבית, הפרק, אזור ההורים. |
| `server.js` | שרת סטטי + מקום לשירות קול בענן; מפתחות רק במשתני סביבה בצד השרת. |
| `docs/` | הדקות הראשונות, העונה, תהליך אישור תוכן. |

## מה דורש שירות או נכס חיצוני
- **קולות הדמויות**: כרגע קולות המערכת של המכשיר (Web Speech), עם שינוי גובה וקצב לכל דמות. איכות הקול משתנה בין מכשירים; ב־iPad יש קול עברי מובנה, בחלק ממכשירי Android צריך להתקין חבילת קול עברית. לחוויה ברמת סדרה צריך הקלטות שחקנים/ות או TTS איכותי מאושר – החיבור מוכן ב־`/api/tts` בצד השרת.
- **זיהוי דיבור**: Web Speech Recognition – זמין ב־Chrome/Edge/Safari, לא ב־Firefox. בחלק מהדפדפנים העיבוד נעשה בשרתי הספק. כבוי כברירת מחדל.
- **מוזיקה**: צלילים מסונתזים בלבד. שירים מקוריים מוקלטים לפרק הלהקה – נכס חיצוני.
- **גופן**: Rubik מ־Google Fonts (נופל לגופן מערכת בלי רשת).
